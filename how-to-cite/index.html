Cómo citar este Cookbook

El material consignado en este Cookbook tiene licencia abierta para su uso y reutilización. Todos los códigos son servidos bajo Apache 2.0, mientras que todo el contenido que no es código tiene licencia Creative Commons BY 4.0 (CC BY 4.0). Efectivamente, esto significa que usted es libre de compartir y adaptar este material siempre que dé el crédito correspondiente a los autores del Cookbook y a la comunidad del Proyecto Pythia. La parte de fundamentos de Python y Jupyter Lab, al igual que la sección de Numpy, Pandas y Xarray utiliza material de Pythia Foundations adaptado de tal manera que puedan ser tratados durante la duración del curso.

El código fuente para este libro está disponible en GitHub y almacenado en Zenodo. El DOI siempre estará ligado a la versión más reciente de este libro:

Si el material de Ciencia de Datos Hidrometeorológicos con Python es útil en un trabajo publicado, puede citar una versión específica del libro como:

Ladino-Rincon A., Rivera N., Ruales-Hernández L., Grover M. (2025), Ciencia de Datos Hidrometeorológicos con Python. Zenodo. Alfonso Ladino et al. (2023)

Reconocimientos¶

Este libro nace a partir del Taller de datos científicos con Python y R - AtmosCol 2023, y ha evolucionado como un recurso educativo permanente para la comunidad de ciencias atmosféricas de América Latina.
